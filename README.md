## Aether Online

![Tests](https://github.com/vesperlabs/aether/actions/workflows/tests.js.yml/badge.svg)

A TypeScript MMO using `PhaserJS` and `SocketIO`.

## ⚡️ Quick start

```bash
npm install
npm run dev # server, client and wiki together
```

See [CONTRIBUTING.md](CONTRIBUTING.md) for setup details, environment, tooling and the roadmap, and [ARCHITECTURE.md](ARCHITECTURE.md) for how the code is organized.
